Please find attached the link to the GitHub repo for the RowHammer gem5 simulator code and the tutorial slides for the ACA project. The provided code is of gem5 version 23.0.1.0.


Note: Follow these steps to set up the simulator first and then run the sample codes provided in the slides (also present in the store folder in this repo) to get a brief idea of the process and the folder structure.


Repo: https://github.com/sudipto0315/gem5-rowhammer (branch: develop)

The instructions below assume Ubuntu 22.04.

1. Install the prerequisites

sudo apt install -y build-essential scons python3-dev python3-pip python3-venv \
    git m4 zlib1g-dev pkg-config unzip wget \
    libprotobuf-dev protobuf-compiler libprotoc-dev \
    libboost-all-dev libhdf5-dev libpng-dev libelf-dev libcapstone-dev \
    libgoogle-perftools-dev

2. Clone the repo and its JSON dependency

git clone https://github.com/sudipto0315/gem5-rowhammer
cd gem5-rowhammer/ext/json
git clone https://github.com/nlohmann/json.git
cd ../..

This second clone is required. HammerSim reads the DRAM device map using nlohmann/json.

3. Unpack the DRAM device map

unzip util/hammersim/prob-005.json.zip -d util/hammersim/


The device map is the list of weak cells in the DRAM device. HammerSim uses this map to decide which bits flip. It ships compressed in the repo and must be unpacked before you run any simulation. This produces util/hammersim/prob-005.json. The extracted file is listed in .gitignore, so it will not show up as a local modification.

Please also refer to README-RH.md for the JSON format and other information about the HammerSim.

4. Build the binary

scons -j$(nproc) build/X86/gem5.opt USE_ARM_ISA=y



For building this specific version of gem5 binary "USE_ARM_ISA=y" option is required by default but it doesn't means that the binary was built for ARM ISA. This option is only present for linking related files and nothing more. 


5. Verify the build

./build/X86/gem5.opt -q -c "import _m5.core; print(_m5.core.gem5Version)"


This should print 23.0.1.0.

6. For Full-system mode: kernel and disk image  


    a. Download the Linux kernel
   
    Fetch the prebuilt x86 kernel into gem5's resource cache, saving it under the name the run scripts expect:

    mkdir -p ~/.cache/gem5
    wget https://dist.gem5.org/dist/develop/kernels/x86/static/vmlinux-5.4.0-105-generic -O ~/.cache/gem5/x86-linux-kernel-5.4.0-105-generic

    b. Build the Ubuntu disk image

    The image is built with Packer inside a QEMU VM using KVM acceleration, so install QEMU and give your user access to /dev/kvm first:

    sudo apt install -y qemu-system-x86 qemu-utils
    sudo usermod -aG kvm $USER


    Log out and back in for the group change to take effect. You need this for the simulation itself as well, since the full-system scripts boot on gem5's KVM cores.

    Then build the image:

    git clone https://github.com/kaustav-goswami/gem5-resources.git
    cd gem5-resources
    git checkout rowhammer
    cd src/rowhammer-fs
    ./build-x86.sh 22.04

The finished image lands at:

gem5-resources/src/rowhammer-fs/x86-disk-image-22-04/x86-ubuntu
